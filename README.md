# 三玉社區踏查地圖

二年級社區踏查用的 3D 互動地圖。學生從學校出發，依序走過 6 個社區地點，每站完成生活、數學、國語任務拿印章，最後回到學校寫一封感謝信。

- 不用登入，不收集個資；進度只存在該裝置的瀏覽器
- iPad：點「走到下一站」或點站牌；單指拖曳轉視角、雙指縮放
- 教師大屏：⚙️ → 大屏模式（字放大）、老師模式（每站都能去）
- 🗺️ 看全圖；🔊 念題目給學生聽
- ⚙️ → 📷 換上照片：每站匯入班上實拍照片（只存在該裝置，可匯出／匯入設定檔）
- ⚙️ → 注音開關

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `data/tour.js` | **路線、站點、題目**（要改題目只改這裡） |
| `js/game.js` | 3D 畫面與互動（最上面的 `LOOK` 是畫面風格數值：亮度、燈光、霧面程度、地面／道路色票） |
| `js/art.js` | 小遊戲的角色與圖示（SVG，風格照 class-games） |
| `index.html` | 頁面與樣式 |
| `js/zhuyin.js` | 注音字典（由 `tools/build-zhuyin.js` 產生；多音字改 `tools/zhuyin-overrides.js`） |
| `vendor/three.min.js` | Three.js r149（放在本機，不靠外部 CDN） |

數學題的數字都是假設情境，不是真實資料。
