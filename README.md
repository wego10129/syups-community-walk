# 三玉社區踏查地圖

二年級社區踏查用的 3D 互動地圖。學生從學校出發，依序走過 6 個社區地點，每站完成生活、數學、國語任務拿印章，最後回到學校寫一封感謝信。

- 不用登入，不收集個資；進度只存在該裝置的瀏覽器
- iPad：點「走到下一站」或點站牌；單指拖曳轉視角、雙指縮放
- 教師大屏：⚙️ → 大屏模式（字放大）、老師模式（每站都能去）
- 🗺️ 看全圖
- ⚙️ → 📷 換上照片：每站匯入班上實拍照片（只存在該裝置，可匯出／匯入設定檔）
- ⚙️ → 注音開關

## 三種使用方式（每次打開都會跳出選單；上方彩色按鈕可以隨時切換）

| 方式 | 誰操作 | 做什麼 |
| --- | --- | --- |
| 出發前・行前說明 | 老師大屏 | 看行前規則、路線、每一站要做的事；只看不答 |
| 踏查後・全班回顧 | 老師大屏 | 全班一起作答、拿印章 |
| 踏查後・學生平板 | 學生 | 各自作答，最後寫明信片，按「交給老師」存成圖片 |

**學生專用網址**：網址後面加 `?student`（例如 `https://<帳號>.github.io/syups-community-walk/?student`）。學生平板打開就直接進入「踏查後・學生平板」，不會跳出選單，也看不到切換方式、換照片、老師模式。老師選單裡的「學生平板」卡片有這個網址和「複製網址」按鈕。

三種方式的進度和人物停在哪一站**分開記錄**，切換不會互相影響；每張卡片都有「從頭開始」（按兩次才會清除）。

**回到某一站**：點上方的印章或地圖上的地點，人物會直接回到那一站。老師大屏（出發前、全班回顧）每一站都能去；學生平板只能去下一站和完成過的站（⚙️ 打開老師模式就不限制）。

**明信片怎麼收**：學生要填好班級、座號、名字才能寄出（班級會記在這台平板，下一位不用再填）。按「交給老師（存成圖片）」，iPad 會跳出分享選單，可以直接傳到 LINE、Google 雲端硬碟或 AirDrop 給老師；不支援分享、或分享失敗的裝置會下載成 `postcard-班級-座號-收件人.png`（例如 `postcard-03-05-post.png`）。明信片上有學生姓名，請只傳給老師，不要轉貼到公開的地方。

**一台平板輪流用**：學生寄出明信片後，下方有「換下一位同學（清除這台平板的進度）」，按兩次會清掉學生平板的進度、人物回到第一站，班級保留。

**家長分享頁**：網址後面加 `?share`（例如 `https://<帳號>.github.io/syups-community-walk/?share`）。只顯示 `share/photos.json` 裡的地點照片和每站學了什麼，不顯示答案和學生資料。
1. 老師在 ⚙️ →「換上照片」放好地點照片（不要拍到學生的臉、名牌、班級）
2. 勾選確認後按「匯出家長分享檔」，得到 `photos.json`
3. 上傳到 GitHub 專案的 `share/` 資料夾（取代原本的空檔）
4. 把分享網址貼到班級 LINE 群組

注意：上傳到 GitHub 的照片是公開的，刪掉後也會留在 git 歷史紀錄裡。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `data/tour.js` | **路線、站點、題目**（要改題目只改這裡） |
| `js/game.js` | 3D 畫面與互動（最上面的 `LOOK` 是畫面風格數值：亮度、燈光、霧面程度、地面／道路色票） |
| `js/art.js` | 小遊戲的角色與圖示（SVG，風格照 class-games） |
| `index.html` | 頁面與樣式 |
| `js/zhuyin.js` | 注音字典（由 `tools/build-zhuyin.js` 產生；多音字改 `tools/zhuyin-overrides.js`） |
| `vendor/three.min.js` | Three.js r149（放在本機，不靠外部 CDN） |
| `prompt/社區踏查島提示詞.md` | 給其他學校的提示詞：貼給 Claude，用 Artifact 做出自己學區的踏查地圖 |
| `prompt/tour.template.js` | 資料範本：換成自己的路線與題目；也可以直接存成 `data/tour.js` 沿用本專案 |

數學題的數字都是假設情境，不是真實資料。數學題對應翰林版二上第 1～5 單元（200 以內的數、二位數加減、公分、加減應用、容量），只保留公園一個乘法遊戲。
