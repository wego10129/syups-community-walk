# 三玉社區踏查地圖（精簡版）

二年級社區踏查用的 3D 地圖。**老師在大屏上操作，學生不用碰平板。**
重點是讓孩子覺得：我們真的走過的路，變成了一個可以再走一次的世界。

- 不用登入，不收集個資；走過的紀錄和照片只存在老師這台裝置的瀏覽器裡
- 單指拖曳轉視角、雙指縮放；🗺️ 看全圖
- 注音照 class-games 的做法（注音字型），⚙️ 可以關掉

## 怎麼用

| 時間 | 老師做什麼 |
| --- | --- |
| 出發前 | 按下方的大按鈕，一站一站看：路線、行前約定、「找找看」 |
| 踏查時 | 用手機或平板拍照，**只拍孩子的背影**，不要拍到臉、名牌、書包或水壺上的名字 |
| 回到教室 | 每站卡片上點「放照片」從相簿選照片（一站最多三張），再帶全班「再走一次」：看照片和 3D 對照、「說說看」討論、點開「我們學到」 |
| 結束 | 按「做家長分享圖」，產生一張長圖（地圖＋每站照片＋學到的事），直接傳到班級 LINE 群組 |

- 點上方的地點或地圖上的站牌，人物會直接到那一站。
- 學習單照常用，這個網頁只負責「再走一次」。

**換電腦**：照片只存在這台裝置。⚙️ →「打包下載照片」，到另一台電腦 ⚙️ →「匯入照片」。

**家長分享圖**：做圖前要勾選確認照片只拍到背影。圖只傳到班級群組，不會放到網路上。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `data/tour.js` | **路線、站點、每站的「找找看／說說看／我們學到」**（要改內容只改這裡） |
| `js/game.js` | 3D 畫面與互動（最上面的 `LOOK` 是畫面風格數值） |
| `js/art.js` | 地點圖示（SVG） |
| `index.html` | 頁面與樣式（外框風格照 class-games） |
| `js/zhuyin.js` | 注音字典（由 `tools/build-zhuyin.js` 產生；多音字改 `tools/zhuyin-overrides.js`） |
| `js/bpmf-font.js` | 注音字型（Bpmf Zihi Kai Std，SIL OFL 1.1，只含用到的字），由 `tools/build-bpmf-font.py` 產生 |
| `vendor/three.min.js` | Three.js r149（放在本機，不靠外部 CDN） |

改了 `data/tour.js` 的文字以後，要重新產生注音字典和字型（新的字才會有注音）：

```bash
node tools/build-zhuyin.js .
```

```bash
python3 tools/build-bpmf-font.py . <bpmfvs>/phonetic/phonic_table_Z.txt BpmfZihiKaiStd_400Regular.ttf
```
