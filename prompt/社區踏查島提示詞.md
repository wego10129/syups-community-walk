# 社區踏查島提示詞

> 給其他學校老師用：不會寫程式，也能做出自己學區的 3D 社區踏查地圖。
> 做法：先填好下方的「資料範本」（換成你們的路線和題目），再把整份提示詞貼給 Claude，請它用 Artifact 做出來。

---

## 怎麼用（三步驟）

1. **填資料**：打開 `prompt/tour.template.js`，照註解把學校名稱、站點、題目換成你們的。座標不用精準，照 Google 地圖截圖的相對位置估就好（說明在範本最上面）。
2. **貼給 Claude**：在 claude.ai 開新對話，輸入「請用 Artifact 做一個單一 HTML 檔」，接著貼上下面「提示詞本文」，最後貼上你填好的資料。
3. **分階段看成果**：Claude 會分五個階段交付。每個階段都先打開看看，有問題直接說，例如「站牌太小」「第三題答案錯了」。

**分享前檢查**：Artifact 建立後只有自己看得到，要按分享別人才打得開；拿到連結的人都能看，所以不要放學生照片、姓名、班級。

## 提示詞本文（從這裡開始複製）

### 1. 角色與底線

你是資深 Three.js 工程師，也熟悉國小低年級的教學設計。請做一個「社區踏查 3D 地圖」網頁，給國小二年級學生在 iPad 上使用。

- 只輸出**一個 HTML 檔**，不用建置工具。
- Three.js 用 r149 版，從 `https://cdn.jsdelivr.net/npm/three@0.149.0/build/three.min.js` 以一般 `<script>` 載入（不要用 importmap 或 ES module，老師下載後直接雙擊 HTML 也要能開）。
- **不載入任何圖片、模型、字型檔**。建築、樹、人物都用 Three.js 幾何體畫；圖示用內嵌 SVG；站牌文字用 canvas 畫成貼圖。
- 不需要登入，不收集任何個資；學生進度只存在該裝置的 localStorage。
- 所有內容（路線、站點、題目）都放在檔案最上方的 `DATA` 物件，程式只負責照資料畫。我會在最後貼上 `DATA`。

### 2. 畫面風格（數值照抄，不要自己改）

黏土玩具感來自「色調映射＋霧面材質＋三盞燈＋飽和色票」，不是靠更多模型。

| 項目 | 數值 |
|---|---|
| 色彩管理 | `THREE.ColorManagement.legacyMode = false`；`renderer.outputEncoding = THREE.sRGBEncoding` |
| 色調映射 | `THREE.ACESFilmicToneMapping`，曝光 `0.65`（Three.js 的 ACES 內建會再除以 0.6，所以不要設 1.0，會過曝） |
| 材質 | 一律 `MeshStandardMaterial`，`roughness: 0.78`、`metalness: 0`；同色共用同一個材質 |
| 半球光 | 天空 `0xeaf4ff`、地面 `0xb2c08f`，強度 `0.55` |
| 主光（投影） | `DirectionalLight 0xfff0d8`，強度 `0.95`，位置 `(-30, 60, 20)`，陰影貼圖 2048、`PCFSoftShadowMap` |
| 補光 | `DirectionalLight 0xbcd4ff`，強度 `0.22`，位置 `(40, 30, -35)`，不投影 |
| 背景與霧 | 背景 `0xd6ecfb`；`Fog(0xd6ecfb, 110, 230)` |
| 色票 | 地面 `0x96d46e`、公園草地 `0x7cc75a`、道路 `0xf6cf8a`、溪水 `0x4db6ea`、路面虛線 `0xffffff` |
| 地面 | 300 × 300 平面；道路寬 `2.6`，沿 `DATA.route` 的點一段一段鋪 |
| 建築 | 圓角方塊（倒角約 0.28），站點建築放大 `1.15` 倍，面向最近的道路 |
| 樹 | 樹幹圓柱＋二十面體樹冠（`IcosahedronGeometry(1, 0)`、`flatShading`），三種綠 `0x6cb565 0x5aa35f 0x7dbf6a` |
| 鏡頭 | `PerspectiveCamera` 視角 `45`；跟隨模式距離 12–55（雙指縮放）；全圖模式對準 `(-2, 0, 0)`、距離 `82` |
| 效能 | `setPixelRatio(Math.min(devicePixelRatio, 1.75))`；幾何體與材質都要快取重複使用 |
| 站牌、照片標籤 | Sprite，`depthTest: false`、`toneMapped: false`（標籤顏色不要被色調映射改掉） |

### 3. 固定隨機種子

樹和住家的位置用固定種子產生，每次打開畫面都一樣：

```js
var seed = 11;
function rnd() { seed = (seed * 16807) % 2147483647; return (seed - 1) / 2147483646; }
```

不要用 `Math.random()` 擺放場景物件。

### 4. `DATA` 的格式

照我貼上的 `DATA` 物件，欄位意思如下：

- `title`、`subtitle`：左上角標題。
- `center`：地圖中央的老地名牌（`name`、`note`、`tip`）。
- `river`：溪流的折線點 `[x, z]`，可以沒有。
- `route`：學生走的路線點 `[x, z]`，第一點是學校，最後一點回到學校。
- `stations[]`：每一站有 `id`、`name`、`emoji`、`kind`（決定建築外型：school、temple、bank、post、police、fire、library、park、river；其他值畫成一般建築）、`at`（在 route 的第幾個點）、`pos`（建築位置）、`lookFor`（到現場找找看）、`tasks[]`。最後一站可設 `noBuilding: true`。
- `tasks[].type` 題型：
  - `info`：說明文字（`text`）。
  - `choice`：單選（`q`、`options`、`answer` 從 0 起算、`why` 解說）。
  - `math`：乘法情境，先選列式再選答案（`story`、`per` 一份幾個、`groups` 幾份、`unit`、`ask`）。被乘數（per）寫在前面。
  - `order`：依序點選詞語排句子（`items` 依正確順序填，畫面會打亂）。
  - `sort`：分類小遊戲，一次一張卡片，點正確的籃子（`bins`、`items[].bin`）。
  - `chase`：判斷可以／不可以（`items[].ok`、`why`）；答錯的題目稍後再出一次。
  - `run`：看圖列式，每答對一題畫面上一個圖示改變（`rounds[]`，每回合 `q`、`per`、`groups`、`unit`）。
  - `pick2`：從選項選出兩個（`answer` 是兩個序號）。
  - `letter`：最後寫明信片，從 `recipients[].lines` 挑一到兩句；明信片用 canvas 畫，左邊稿紙格一格一字（兩個阿拉伯數字一格）、右邊郵票和收件人，寄出後蓋郵戳，可用 Web Share 存成 PNG 交給老師。
  - 二上數學：`place`（幾個百十一）、`pay`（點錢幣付錢）、`word`（二位數加減，附驗算）、`compare`（＞＜＝）、`measure`（用尺量公分）、`capacity`（幾杯水倒滿）。每題可加 `lesson` 標課本單元。
- `rules`：行前規則（字串陣列）。
- 三種使用方式：出發前（老師大屏，只看不答）、踏查後全班（大屏作答）、踏查後學生平板。網址加 `?share` 是給家長的唯讀頁，只讀 `share/photos.json`。

### 5. 分五個階段交付，每個階段都要能打開執行

1. **場景骨架**：renderer、燈光、色調映射、地面、道路、溪流、固定種子的樹與住家、鏡頭拖曳旋轉與雙指縮放、全圖按鈕。
2. **建築與站牌**：依 `kind` 畫各站建築，站牌（canvas 文字＋SVG 圖示）浮在建築上方，下一站的站牌上下跳動。
3. **任務介面**：點站牌或「走到下一站」開啟任務卡，依題型出題、答對給印章，進度存 localStorage；上方一排印章列。
4. **小人走路**：學生角色沿 `route` 走到下一站，鏡頭跟隨；走到時自動開任務卡。
5. **收尾**：
   - 載入失敗（例如沒有 WebGL、CDN 被擋）時顯示中文錯誤訊息，不要白畫面。
   - 支援 `prefers-reduced-motion`：開啟時不跳動、走路直接瞬移。
   - 大字模式（教師大屏用）與「老師模式」（每站都能直接進入）。
   - 「念題目」按鈕用瀏覽器內建的 `speechSynthesis`，語言 `zh-TW`。
   - 按鈕至少 44px 高，給小朋友的手指點。

### 6. 文字與內容規則

- 介面文字用繁體中文，句子短，二年級看得懂。
- 數學題的數字都是假設情境，題目裡寫「假設」。
- 不放真實人名、學生姓名或照片。

## 注意事項（給老師看，不用貼給 Claude）

- **注音**：原版三玉地圖有自動注音，靠的是一份另外產生的注音字典，單一 HTML 版做不到同樣效果。需要注音的話，可以在題目裡直接用括號標，或請 Claude 改用支援注音的字型。
- **學校網路會不會擋 jsdelivr**：各校設定不同，請先在教室的 iPad 打開試試。被擋的話，請資訊組把 Three.js 下載下來和 HTML 放在一起，`<script src>` 改成本機路徑。
- **學校建築**：本專案的 `school` 外型是照三玉國小空拍圖做的（前棟、操場、跑道），換學校時校名會自動換，配置不會；要改配置請 Claude 依你們的空拍圖重畫。
- **原始專案**：三玉國小的完整版本（含注音、照片匯入、小遊戲角色）在本專案的 `index.html`、`js/`、`data/tour.js`。
